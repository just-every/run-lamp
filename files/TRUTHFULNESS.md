# Behavioral wording review

Run Edit Run fleet, 17 November 2026 (UTC).

- Local email is suppressed by `isLocalMailExecution` and `createAppMailTransport` in `src/core/app/mail.ts`, using `developmentMail()`. The mail-settings endpoint reports the composed transport mode and active provider, not an inferred deployment name. The local subscriber journey exercises the real silent transport and its suppressed delivery outcomes. The inactive From field can be hidden while the stored value remains in collapsed Details.
- “Doesn’t send emails or texts” is conditional: no active mail provider/local suppression, plus SMS `configured === false`. `src/core/features/sms/service.ts` requires usable Twilio inputs, management tokens, unpaused effects and a hosting plan that permits sending. A configured SMS channel does not receive the no-text claim. Pending SMS configuration produces an email-only statement until known.
- The online/local reachability statement is gated by the product's live public origin being a loopback host and not a hosted preview. It is hidden for an online hostname. This is the same loopback interpretation the existing page hero uses. Browser proof uses a local install, not a public-host inference.
- Email language is qualified to confirmed subscribers and published updates. `src/core/app/services.ts`, subscriber consent and delivery flows preserve confirmation, channel selection and suppression. The wording does not promise mailbox receipt merely because a provider is configured.
- Automatic maintenance start/completion is implemented by `runDue` in `src/core/features/maintenance/service.ts`, which checks saved per-window automation and performs guarded transitions and notices. The Overview times read the saved start/end and configured page timezone. “Nothing for you to do” applies to the future automatic steps. A still-scheduled start past its time or an in-progress automatic completion past its time appears as a failed follow-up.
- Main's newer reminder rules are preserved: advance announcements can have a future reminder obligation; a notice already within the lead window produces none. This obligation is distinct from automatic start/completion and is not removed by this round.
- Technical input names, deployment instruction and stored From address remain available in one collapsed Details block and the existing linked guide. Existing unrelated legacy prose is retained.
